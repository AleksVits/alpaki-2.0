# UI work in this repository

Before creating or changing any website section, read `DESIGN_SYSTEM.md` and treat it as the source of truth for visual language, spacing, responsive behavior, galleries, motion, and controls.

Reuse the existing components and CSS tokens. Keep phone, tablet, laptop, 1080p, 2K, and 4K layouts consistent. If an intentional exception is introduced, document it in `DESIGN_SYSTEM.md` in the same change.
